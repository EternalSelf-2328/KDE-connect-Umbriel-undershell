# Catálogos de español del motor integrado

Fuentes gettext de KDE Connect 26.08.3, conservadas con los créditos y licencias
originales de cada catálogo. Se usan en el prefijo privado de Umbriel Connect;
no necesitan la instalación del programa KDE Connect.

Origen oficial: https://download.kde.org/stable/release-service/26.08.3/src/kdeconnect-kde-26.08.3.tar.xz

SHA256 del archivo de origen:
`f554a190cc15039f12af14b1f4ccdb3754a308327623a750bc3f4f59b59239fd`.

Los identificadores de catálogo y los espacios de nombres QML conservan su nombre
original para que los mensajes se resuelvan. No son servicios ni ejecutables externos.
Los mensajes añadidos después de esta versión pueden aparecer en inglés.
